# Code of conduct

These repositories are maintained by a very small team for a community of
members who use the plugins every day. Two rules cover almost everything.

1. **Be kind and be specific.** Report what happened, what you expected,
   and how to reproduce it. Disagree with the code, not with the person.
2. **Respect the maintainers' time.** Read the README and `CONTRIBUTING.md`
   before opening an issue or a pull request, search for an existing thread
   first, and accept a "no" or a "not now" without reopening it.

Not welcome, anywhere in an issue, pull request, review or discussion:
harassment, insults, discriminatory remarks, publishing someone's private
information, or sustained disruption after being asked to stop.

Anyone who breaks these rules can have a comment hidden, a thread locked,
or their access to the organization's repositories removed. Reports go to
support@myicor.com; they are read by a person, kept private, and answered.
