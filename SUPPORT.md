# Support

What myICOR supports: the plugin as published in a tagged release, on the
current version, installed from that release. Bugs go to the repository's
issues, security reports to the process in its `SECURITY.md`.

What the community maintains: anything marked community-maintained,
including community source adapters. We review it before it is merged. We
do not support it, we cannot promise it keeps working, and it can be
disabled or removed in any release.

What is yours: your own changes, your fork, your local patch. Please
reproduce the problem on a clean install of the current release before
reporting it.

## Where to go

- **A bug in a plugin**: open an issue on that plugin's repository with the
  bug template. One bug per issue, with the plugin version and the Obsidian
  version.
- **A source or integration you wish existed**: the integration request
  template on that plugin's repository.
- **A question, or how-to help**: the ICOR for Life community space at
  https://app.myicor.com/icor-for-life, where members and the team read
  every day.
- **A security problem**: never a public issue. Follow the repository's
  `SECURITY.md`, or write to support@myicor.com.
